-------------------------------------
How to install Playwright with _Javascript:

## Prerequisites
- Node.js installed
- npm installed
if Node.js needs to be installed, find latest package in: https://nodejs.org


1.
in terminal:
cd "Automated Testing"
npm init -y -> package.json will be created

2.
Playwright telepítése:
npm init playwright@latest

in options: choose Javascript
for test directory choose: tests

3.
install dotenv:
in terminal: npm install dotenv
create .env file in root folder
LOGIN_EMAIL=***
LOGIN_PASSWORD=***


-------------------------------------
How to run Playwright tests

1.

in terminal:
npx playwright test --headed

2.
Frontend tests:
npx playwright test --project=frontend

API tests:
npx playwright test --project=api


3.
Start Playwright recorder:
in Powershell: npx playwright codegen https://account.aldi.us/s/login/

View report at:
http://localhost:9323

INTRO: for testing the API calls, it is recommended to set up a Mock server for testing porpuse 

How to set up Mock server for API Testing

1. 
Navigate to Mock folder:
cd "Automation Testing/API Mock" or cd "API Mock"

2.
Install dependencies:
npm install

3.
Start mock server:
npm start

Expected output:
Mock Task API running on http://localhost:3000
